## Stroop Game · 팀 프로젝트

색상 선택 게임에서 문제 전환과 모바일 입력 경험을 개선했습니다.

- [PR #85](https://github.com/rohdaeyoung/stroop-game/pull/85) — 답을 고르면 피드백을 먼저 보여준 뒤 다음 문제로 넘어가도록 전환 순서를 분리하고, 피드백이 표시되는 동안 중복 입력을 막았습니다.
- [PR #86](https://github.com/rohdaeyoung/stroop-game/pull/86) — 모든 난이도에서 네 가지 색상 선택지가 나오도록 통일하고, 터치 후 선택 테두리가 남는 문제를 수정했습니다.

## Dalli · 해커톤 팀 프로젝트

초보 러너가 자신에게 맞는 케이던스(분당 발걸음 수)로 무리 없이 완주하고, 러닝 기록과 계획을 꾸준한 운동 습관으로 이어가도록 돕는 앱입니다.

- **담당** — Expo(iOS) 앱의 UI 프론트엔드. 화면과 라우팅, API 연동, 공통 컴포넌트와 테마를 담당했습니다.

[팀 저장소](https://github.com/Gonu19/Dalli-hackathon) · [화면 및 라우팅 문서](https://github.com/Gonu19/Dalli-hackathon/blob/main/docs/SCREENS.md)
